# Session Brief

Generate a daily summary of work done across your tracked git projects and send it to Telegram.

**Core idea:** Every morning, get a clear picture of what you accomplished yesterday — organized by project, categorized by type (feat / fix / docs), with GSD project status if available.

---

## The Process

### Phase 1: Interview (Grilling)

I'll interview you systematically about your needs. Questions are organized in **rounds**. Each round asks all questions whose answers don't depend on future decisions.

**Format:**
- ❓ = Question  
- ➡️ = My recommended answer (accept or override)
- **After each round**, you answer, and I recompute the frontier for the next round

**The interview is done** when every decision is settled and we reach shared understanding.

---

## Round 1: Core Setup

❓ **Q1** - **Daily Schedule & Telegram**: What time do you want the brief, and do you have a Telegram bot ready?

Options:
- Time: 7 AM / 8 AM / 9 AM / other (timezone?)
- Telegram: Already have bot token & user ID / Need to create / Not sure

➡️ 7 AM Asia/Tokyo. I can guide you through Telegram setup if needed.

---

❓ **Q2** - **Projects to Monitor**: Which projects should I watch? List paths or just tell me how many + which are GSD projects.

Example:
```
/Users/you/project1 (GSD)
/Users/you/project2 (regular)
```

➡️ I'll auto-detect `.planning/STATE.md` and adjust monitoring per project.

---

❓ **Q3** - **What Matters in the Brief**: What should the daily summary focus on?

Options:
- Commits only (what code changed)
- Commits + project status (if GSD)
- Commits + specific files you care about (package.json, Cargo.toml, etc.)

➡️ Commits + project status (most useful for tracking)

---

**Your turn:** Answer Q1-Q3 (or adjust the recommended answers). Once you answer, I'll confirm we have everything and set up your script.

## What Gets Generated

### 1. Config File: `~/.session-brief/config.json`

```json
{
  "telegram": {
    "bot_token": "YOUR_BOT_TOKEN",
    "user_id": "YOUR_USER_ID"
  },
  "schedule": {
    "hour": 7,
    "minute": 0,
    "timezone": "Asia/Tokyo"
  },
  "projects": [
    "/Users/you/Documents/project1",
    "/Users/you/Documents/project2"
  ],
  "monitored_files": [
    ".planning/STATE.md",
    "README.md",
    "package.json"
  ]
}
```

### 2. Script: `~/.session-brief/session-brief.sh`

A bash script that:
- Reads config
- Scans git history for yesterday
- Categorizes commits
- Reads project status (if `.planning/STATE.md` exists)
- Sends to Telegram
- Logs results

### 3. Cron Entry

```bash
0 22 * * * /Users/you/.session-brief/session-brief.sh 2>&1 | logger -t session-brief
```

(Runs at 10 PM UTC = 7 AM Asia/Tokyo)

## Telegram Setup (One-Time)

Before using session-brief, you need:

1. **Create a bot** at @BotFather in Telegram
   - Send `/newbot`
   - Give it a name (e.g., "SessionBriefBot")
   - You'll get a **Bot Token** (looks like `123456:ABC-DEF...`)

2. **Get your User ID**
   - Search for @userinfobot in Telegram
   - Send it any message
   - It replies with your **User ID** (looks like `123456789`)

3. **Start the bot**
   - Search for your bot by name
   - Send `/start`
   - This lets the bot message you

## Troubleshooting

### "chat not found" from Telegram

→ You haven't sent the bot a message yet.
- Search your bot in Telegram
- Send `/start` or any message
- Try again: `/session-brief --test`

### "Config not found"

→ You haven't run setup yet.
- Run: `/session-brief --setup`

### Cron doesn't run

→ Check:
1. Is the script executable? `ls -la ~/.session-brief/session-brief.sh`
2. Is cron installed? `crontab -l | grep session-brief`
3. Check logs: `log stream --predicate 'process == "logger" and eventMessage contains "session-brief"'`
